# Pretty Killer Leaks

Snippets and teasers for Finn Shapiro's Pretty Killer Tour, in the same Pretty (AM) / Killer (PM) style as the shop and tickets sites.

- **Snippets** are song clips: put the `.mp3` in `media/snippets/` (and an optional cover picture).
- **Teasers** are videos or pictures: put the `.mp4` (or the picture, listed with `image` instead of `file`) in `media/teasers/`. Clicking a picture opens it full size.
- List each one in `LEAKS` at the top of the script in `index.html`, newest first, with its type, side (`pretty`, `killer` or `both`), title, an optional note and the date.
- The tabs filter **All / Snippets / Teasers**. With nothing listed, the page says "Nothing leaked yet".
- **Testing:** type `am` or `pm` anywhere on the page to switch sides, and `auto` to follow the clock again.
